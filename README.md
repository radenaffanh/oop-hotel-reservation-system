# Hotel Reservation System

Hotel room booking system in C++ with Standard, Deluxe and Suite rooms using inheritance.

## Features

- Room base class with Standard, Deluxe and Suite subclasses
- Per-night pricing for each room type
- Booking summary with guest name, nights and total cost

## How to run

```bash
g++ hotel_reservation.cpp -o hotel_reservation
./hotel_reservation
```
